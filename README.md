# ⚙️ Operations & Talent Automation Portfolio

This repository contains custom-built, AI-powered applications designed to solve expensive operational bottlenecks across Human Resources, Talent Acquisition, and Customer Operations. 

These projects demonstrate the ability to move beyond off-the-shelf SaaS platforms by building scalable, programmatic workflows that reduce manual admin time and improve business SLAs.

## 🚀 The Projects

### 1. 🎯 AI-Powered Resume Matcher (`resume_matcher.py`)
* **Business Value:** Eliminates top-of-funnel manual screening bottlenecks for lean recruiting teams.
* **Features:** Ingests raw applicant resumes and automatically scores/ranks them against specific job descriptions using targeted Prompt Engineering.

### 2. 🧭 Internal Mobility & Skills Gap Mapper (`mobility_app.py`)
* **Business Value:** Drives internal promotion pipelines and reduces external hiring costs.
* **Features:** Evaluates current employee competencies against target roles and auto-generates customized 4-week upskilling roadmaps.

### 3. 🎫 Automated Support Ticket Triage Engine (`triage_app.py`)
* **Business Value:** Reduces Customer Support SLA response times by automatically categorizing unstructured inbound tickets.
* **Features:** AI-driven severity classification (Low to Critical), intelligent department routing, and automated generation of empathetic first-touch draft responses.
